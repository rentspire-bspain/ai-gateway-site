# ai.spaincos.com gateway facts (as of 2026-10-31)
The Spain Terminal AI assistant at ai.spaincos.com answers through the gateway-chat function. The default model for general questions is DeepSeek V4.1 Flash (deepseek/deepseek-v4.1-flash-1017) via OpenRouter. It is a paid model costing roughly $0.0003 per question (about three hundredths of a cent), not free. A daily tripwire of 2000 paid calls (about $0.60) downgrades to the free Qwen3.8-27B model on Groq. If the default errors or returns nothing, the gateway falls back to Qwen3.8-27B and then to Flint v1.0 (free, OpenRouter). The model picker also offers Flint v1.0 and Qwen3.8-27B (fast summary). Answers can include Spain Terminal documentation excerpts retrieved per question, shown as numbered sources.
