Public API reference

Phase 1. Every contract below is generated from the live endpoints themselves — an unauthenticated GET on either route returns the same JSON contract shown here.

Authentication

Both POST routes require Authorization: Bearer . Credentials are never accepted in query strings and never logged or returned.

  • API keys: BoundView API keys from Settings → API Keys. Keys are stored SHA-256 hashed (api_keys.key_hash); revoked or unknown keys return 401. Key holders must be on the same owner/QA allowlist as the web app.
  • User JWTs: the auth project validates the token remotely; locally-decoded JWTs are not trusted.
Phase 1 limits (honest): no usage ledger is written and no credits are charged yet; the distributed rate limiter is LIVE (a Postgres fixed-window counter keyed to your API key or user, 60 requests/minute by default, Retry-After on 429). Do not build production traffic against this surface until those ship.

POST /api/search

query is a non-empty string up to 300 characters. mode defaults to search; quick, search, and deep cap the response at 3, 6, and 12 results respectively — modes change breadth, not a multi-step research budget, and are not guarantees of result count.

curl https://boundview.com/api/search \
  -H "Authorization: Bearer ${BOUNDVIEW_API_KEY}" \
  -H 'Content-Type: application/json' \
  -d '{"query":"renewable energy storage","mode":"search"}'
{
  "object": "search.results",
  "query": "renewable energy storage",
  "mode": "search",
  "results": [
    {"rank": 1, "title": "Example", "url": "https://example.com/", "excerpt": "…"}
  ],
  "provider": "gateway-proxy | sonar | free-sources"
}

Ranking is provider relevance order with deduplication; the provider field tells you which lane served the request.

POST /api/embeddings

input is a non-empty string or an array of 1–32 non-empty strings, at most 32,000 total characters. model defaults to text-embedding-3-small (1536 dimensions). Responses are validated: sequential indices, the exact requested model, 1536 finite numeric dimensions, and safe token-usage integers; only public fields are relayed.

This route returns 503 embeddings_not_configured until the dedicated embeddings upstream is configured. It deliberately never touches the gateway's embed_context path, which mutates stored personal documents.

Errors

HTTPMeaning
400Invalid input
401Missing or invalid credentials
403Private-account restriction
405 / 413 / 415Wrong method / body over 128 KiB / non-JSON
429Upstream limit
502 / 503 / 504Bad upstream / unconfigured or unavailable / timeout

Errors are JSON {"error":{"message","type","code"}}. Provider bodies and secrets are never included.

CORS and methods

Wildcard origins, no cookies or credentialed CORS; only GET (self-documentation), POST, and OPTIONS with Authorization and Content-Type headers. Auth is checked on every POST.
