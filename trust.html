Trust and security

Security, compliance and data-governance evidence for ai.spaincos.com · Updated November 26, 2026

Status at a glance

SOC 2 Type II Inclusion program active (since 2026-11-11) — not yet certified. Owner rulings recorded; audit-window evidence collection in progress.

Data retention 12-month conversation-retention policy live, enforced by a daily automated job with logged per-table outcomes.

Change management Integrity-only branch protection: required live-site verification check, force pushes and deletions blocked (admins included).

Monitoring Minute-scale estate heartbeat, 5-minute production sweeps, hourly data-layer test suites, regression auto-filing.

SOC 2 readiness

The platform is in a documented SOC 2 Type II inclusion program. The authoritative references are the governance record (retention policy and change-management rulings) and the phased hardening plan maintained in the security repository. Evidence under collection: retention-job logs, change-management records (PR + required checks), access reviews, and the monitoring/incident record.

How we build and run it

  • Every production change ships through a pull request with required checks; force pushes and branch deletions are blocked for everyone, including admins.
  • A post-deploy verification guard fails red if production does not match the shipped code.
  • Row-level security on user data; export and deletion available in-product.
  • Sub-processors: hosting/edge (Vercel), database and auth (Supabase), payments (Stripe). Current list available in the questionnaire pack.
